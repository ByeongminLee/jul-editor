JulEditor ships as three npm packages: `@jul-editor/core`, `@jul-editor/react`, and `@jul-editor/plugins` (chart, diagram, table, code, code workspace, data, and diff). It supports React 18 and 19. Heavy renderers are optional peer dependencies, so you install only what you use.

## Install

```sh
pnpm add @jul-editor/core @jul-editor/react react react-dom
# optional plugins, plus the peer each one renders with
pnpm add @jul-editor/plugins
pnpm add recharts   # chart
pnpm add mermaid    # diagram
pnpm add lowlight   # code highlighting
```

npm and yarn work the same way (`npm install @jul-editor/core @jul-editor/react`). A plugin whose peer is missing falls back to a plain status message or unhighlighted code instead of throwing.

## Run the docs site from source

To try the examples locally or contribute, clone the repository.

```sh
git clone https://github.com/ByeongminLee/jul-editor.git
cd jul-editor
pnpm install
pnpm --filter web dev
```

Vite serves the site at `http://127.0.0.1:5190`. You can edit the package source and see the web example update because Vite aliases the workspace packages to their source entry points.

## Check a change

When contributing, run type checking before building. The web Playwright suite starts its own local server, so you do not need to leave `dev` running for it.

```sh
pnpm typecheck
pnpm --filter web build
pnpm e2e:web
```

<Note>

The published packages work with Node.js 20 or newer. Developing in the repository requires Node.js 24 or newer and pnpm 12.

</Note>
