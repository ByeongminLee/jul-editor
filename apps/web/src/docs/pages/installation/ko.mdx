JulEditor는 pnpm 워크스페이스에서 개발합니다. 예제 사이트와 플레이그라운드는 소스에서 실행하며 npm 배포는 준비 중입니다. 워크스페이스는 `@jul-editor/core`, `@jul-editor/react`, `@jul-editor/plugins`(차트·다이어그램·표·코드·코드 워크스페이스·데이터·문서 비교) 세 패키지로 구성됩니다. 무거운 렌더러는 선택형 peer 의존성이라 쓰는 것만 설치하면 됩니다.

## 설치

```sh
pnpm add @jul-editor/core @jul-editor/react react react-dom
# 선택형 플러그인과, 각 플러그인이 렌더링에 쓰는 peer
pnpm add @jul-editor/plugins
pnpm add recharts   # 차트
pnpm add mermaid    # 다이어그램
pnpm add lowlight   # 코드 하이라이트
```

peer가 없으면 해당 플러그인은 오류 대신 안내 문구나 하이라이트 없는 코드로 표시됩니다.

## 사이트 실행

```sh
git clone <repository-url> jul-editor
cd jul-editor
pnpm install
pnpm --filter web dev
```

Vite는 `http://127.0.0.1:5190`에서 사이트를 엽니다. Vite가 워크스페이스 패키지를 소스 진입점에 연결하므로 패키지를 고치면 웹 예제에도 바로 반영됩니다.

## 변경 사항 확인

빌드 전에 타입 검사를 실행하세요. 웹 Playwright 테스트는 자체 로컬 서버를 시작하므로 `dev`를 계속 켜 둘 필요가 없습니다.

```sh
pnpm typecheck
pnpm --filter web build
pnpm e2e:web
```

<Note>

현재 저장소는 Node.js 24 이상을 요구합니다. 설치 전 루트 `package.json`의 지원 버전을 확인하세요.

</Note>
