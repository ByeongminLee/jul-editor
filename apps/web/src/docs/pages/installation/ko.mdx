JulEditor는 npm 패키지 세 개로 배포됩니다. `@jul-editor/core`, `@jul-editor/react`, `@jul-editor/plugins`(차트·다이어그램·표·코드·코드 워크스페이스·데이터·문서 비교)이며 React 18과 19를 지원합니다. 무거운 렌더러는 선택형 peer 의존성이라 쓰는 것만 설치하면 됩니다.

## 설치

```sh
pnpm add @jul-editor/core @jul-editor/react react react-dom
# 선택형 플러그인과, 각 플러그인이 렌더링에 쓰는 peer
pnpm add @jul-editor/plugins
pnpm add recharts   # 차트
pnpm add mermaid    # 다이어그램
pnpm add lowlight   # 코드 하이라이트
```

npm이나 yarn도 똑같이 쓸 수 있습니다(`npm install @jul-editor/core @jul-editor/react`). peer가 없으면 해당 플러그인은 오류 대신 안내 문구나 하이라이트 없는 코드로 표시됩니다.

AI 코딩 에이전트를 쓴다면 [AI 에이전트 스킬](/docs/ai-skill)을 설치하세요. Claude Code나 Codex가 이 설정을 대신 해 줍니다.

## 소스에서 문서 사이트 실행

예제를 로컬에서 돌려 보거나 기여하려면 저장소를 받으세요.

```sh
git clone https://github.com/ByeongminLee/jul-editor.git
cd jul-editor
pnpm install
pnpm --filter web dev
```

Vite는 `http://127.0.0.1:5190`에서 사이트를 엽니다. Vite가 워크스페이스 패키지를 소스 진입점에 연결하므로 패키지를 고치면 웹 예제에도 바로 반영됩니다.

## 변경 사항 확인

기여할 때는 빌드 전에 타입 검사를 실행하세요. 웹 Playwright 테스트는 자체 로컬 서버를 시작하므로 `dev`를 계속 켜 둘 필요가 없습니다.

```sh
pnpm typecheck
pnpm --filter web build
pnpm e2e:web
```

<Note>

배포된 패키지는 Node.js 20 이상에서 동작합니다. 저장소에서 개발하려면 Node.js 24 이상과 pnpm 12가 필요합니다.

</Note>
