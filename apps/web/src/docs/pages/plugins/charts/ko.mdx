차트는 선택해서 추가하는 문서 블록입니다. 문서에 함께 저장할 데이터는 **CSV** 또는 **JSON**으로 직접 입력하고, 별도 파일은 **URL**을 선택해 CSV/JSON 주소를 연결할 수 있습니다. 외부 데이터를 쓸 때 문서에는 주소와 형식만 저장됩니다. 아래 차트를 누르면 차트 종류, 데이터, 축, 색상 설정을 열 수 있습니다.

## 같은 데이터로 만드는 차트 여섯 가지

막대는 범주를 비교하고, 꺾은선은 변화를, 영역은 규모를 보여 줍니다. 원형은 비율, 레이더는 지표 비교, 방사형은 단일 수치를 표현합니다. 여섯 종류 모두 같은 데이터 소스를 사용합니다. 축 설정은 종류에 따라 달라집니다. 막대·꺾은선·영역은 범주 열 하나와 숫자 계열 여러 개를, 원형·방사형(radial)은 레이블과 값 하나를, 레이더는 축 열과 계열 여러 개를 선택합니다.

## CSV 또는 JSON 직접 입력

JSON 데이터는 중첩되지 않은 객체의 배열입니다. 차트에 표시할 값은 숫자로 입력하세요. 형식을 바꿔도 CSV와 JSON 입력 내용은 각각 유지되므로 저장 전에 비교할 수 있습니다. 입력하는 동안 데이터를 검사해 오류가 있으면 바로 아래에 표시하고, 인식된 열 이름·타입·행 수를 미리 보여 줍니다. **샘플 불러오기**는 예시 데이터를 채웁니다. 선택한 `x`나 `y` 열이 사라지면 차트가 적절한 열을 자동으로 고릅니다.

```tsx
import type { Doc } from "@jul-editor/core";
import { Editor } from "@jul-editor/react";
import { ChartView, chartSlashItem } from "@jul-editor/plugins/chart";

const doc: Doc = { version: 1, blocks: [{
  id: "visitors-chart", type: "chart",
  props: {
    kind: "area", x: "월", y: "방문자",
    source: { type: "inline", format: "json", json:
      '[{"월":"1월","방문자":120},{"월":"2월","방문자":160}]' },
  },
}] };

<Editor defaultValue={doc}>
  <Editor.Plugin renderers={{ chart: ChartView }} slashItems={[chartSlashItem]} />
  <Editor.Content />
</Editor>
```

## 차트 props

| Prop | 타입 | 설명 |
| --- | --- | --- |
| `kind` | `"bar" \| "line" \| "area" \| "pie" \| "radar" \| "radial"` | 차트 종류. 기본값 `"bar"`. |
| `x` | `string` | 범주(또는 레이블) 열. |
| `y` | `string \| string[]` | 값 열. 막대·꺾은선·영역·레이더는 숫자 계열 여러 개를 지정할 수 있습니다. 기존 문서의 문자열 값도 그대로 동작합니다. 원형과 radial은 첫 번째 값만 사용합니다. |
| `colorBy` | `"series" \| "category"` | `"category"`는 막대마다 다른 색을 씁니다(계열이 하나인 막대 차트의 기본값). `"series"`는 계열마다 한 가지 색을 씁니다(그 외 기본값). |
| `palette` | `string[]` | 테마보다 우선하는 차트별 색상 목록. 계열이나 범주가 더 많으면 색상이 반복됩니다. |

## 색상

차트는 기본적으로 다채롭게 표시됩니다. 계열마다 색이 다르고, 계열이 하나인 막대 차트는 범주마다, 원형과 radial은 조각마다 8가지 색을 순환해서 씁니다. 에디터의 색상 영역에서 프리셋 팔레트를 고르거나 색상 칸마다 직접 바꾸고, 초기화 버튼으로 테마 기본값으로 되돌릴 수 있습니다. 바꾼 색은 블록에 `palette`로 저장됩니다. 색상 선택기에서 드래그하는 동안에는 칸만 바뀌어 보이고, 선택기를 닫거나 포커스를 잃을 때 블록에 한 번만 기록되므로 한 번의 편집은 실행 취소 한 단계입니다. 칸 하나를 바꾸면 8개 항목이 모두 저장되지만, 건드리지 않은 칸은 `var(--chart-N, 기본색)`으로 저장되어 계속 테마를 따르고 바꾼 칸만 고정 색이 됩니다.

앱 전체 색상은 차트의 상위 요소에 CSS 변수 `--chart-1`부터 `--chart-8`까지 지정하세요. 지정하지 않으면 라이트·다크 테마에서 모두 잘 보이는 기본 색이 쓰입니다. `ChartView`의 `theme.series` 배열로도 같은 변수를 코드에서 지정할 수 있습니다. 블록의 `palette`는 항상 테마보다 우선합니다.

```css
:root {
  --chart-1: #e8833a; --chart-2: #4a90c2; --chart-3: #5aa469; --chart-4: #c9566b;
  --chart-5: #8e6fc4; --chart-6: #d4a82f; --chart-7: #2fa7a0; --chart-8: #8a93a6;
}
```

```tsx
// 두 계열의 꺾은선 차트에 이 차트만의 팔레트를 지정합니다.
{ id: "c1", type: "chart", props: {
  kind: "line", x: "월", y: ["방문자", "가입"],
  palette: ["#3c94b7", "#f2784b"],
  source: { type: "inline", csv: "월,방문자,가입\n1월,120,30\n2월,160,44" } } }
```

## URL의 CSV 또는 JSON 파일

외부 파일을 읽으려면 리졸버를 연결하세요. `createFetchResolveData`에는 앱의 fetch 함수를 전달할 수 있어 S3 서명 URL, CDN, 자체 API를 사용할 수 있습니다. 기본 리졸버는 네트워크 요청을 하지 않습니다. 브라우저에서 다른 출처의 파일을 읽으려면 파일 서버의 CORS 설정도 필요합니다.

```tsx
import { Editor } from "@jul-editor/react";
import { ChartView, ResolveDataProvider, createFetchResolveData } from "@jul-editor/plugins/chart";

const resolveData = createFetchResolveData();
const doc = { version: 1, blocks: [{
  id: "remote-chart", type: "chart",
  props: { kind: "bar", x: "month", y: "visitors",
    source: { type: "url", format: "json",
      url: "https://cdn.example.com/data/visitors.json" } },
}] };

<ResolveDataProvider value={resolveData}>
  <Editor defaultValue={doc}>
    <Editor.Plugin renderers={{ chart: ChartView }} />
    <Editor.Content />
  </Editor>
</ResolveDataProvider>
```

비공개 DB 레코드는 `source: { type: "view", viewId }`로 저장하고, 사용자가 접근할 수 있는 데이터셋으로 ID를 해석하는 리졸버를 제공하세요. Recharts는 차트가 마운트될 때만 로드됩니다. 앱 CSS의 `--chart-1`부터 `--chart-8`까지 지정해 색상을 맞출 수 있습니다.
