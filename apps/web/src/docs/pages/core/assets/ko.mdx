문서에는 파일의 **URL과 메타데이터**를 저장합니다. 파일 검증, 저장소, 인증, S3 연결은 앱이 담당합니다. 붙여넣기·드래그 앤 드롭·파일 선택은 같은 삽입 경로를 사용합니다. 이미지는 바로 미리 보이고, 다른 파일은 선택형 첨부파일 블록을 등록하면 됩니다.

## 업로드 시점 선택하기

- `immediate`는 파일을 넣자마자 `onUpload`를 호출합니다. 파일마다 즉시 업로드할 때 사용하세요.
- `deferred`는 `File`과 이미지 미리보기를 메모리에 보관합니다. 문서를 영구 저장하기 전에 `uploadPending()`을 호출하고 실패가 없을 때 최신 `editor.getDoc()`을 저장하세요.
- `deferred` 모드에서 업로드 함수를 연결하지 않으면 파일은 로컬 대기 상태로 남습니다. `immediate` 모드에 업로드 함수가 없으면 파일 삽입을 건너뜁니다. 문서에는 `File`, `blob:`, `data:` URL이 저장되지 않습니다. 업로드 전에 페이지를 새로고침하면 파일을 복원할 수 없습니다.

업로드 모드는 에디터를 생성할 때 정합니다. 제품마다 정책이 다르면 에디터 인스턴스를 따로 구성하세요.

## 이미지와 첨부파일 넣기

기본 이미지 렌더러는 외부 이미지 URL·대체 텍스트·너비·정렬·캡션을 지원합니다. 이미지 블록을 선택하면 URL을 고칠 수 있습니다. PDF와 다른 파일은 `attachmentBlock`과 `AttachmentView`를 명시적으로 등록하세요. 파일 입력은 `editor.insertFiles(files)`를 호출하면 되고, 붙여넣기와 드롭도 같은 경로로 처리됩니다. `createFileBlock`으로 이미지 외 파일의 블록 형태를 앱에서 바꿀 수 있습니다.

```tsx
import { Editor, useEditor, attachmentBlock, AttachmentView,
  createAttachmentBlock, defaultRenderers } from "@jul-editor/react";

function AddFiles() {
  const editor = useEditor();
  return <input type="file" multiple onChange={(event) => {
    if (event.currentTarget.files)
      editor?.insertFiles(Array.from(event.currentTarget.files));
  }} />;
}

async function uploadAsset(file: File) {
  const body = new FormData();
  body.set("file", file);
  const response = await fetch("/api/assets", { method: "POST", body });
  if (!response.ok) throw new Error("Asset upload failed");
  const result = await response.json() as { src: string; assetId?: string };
  return result;
}

function SaveDocument() {
  const editor = useEditor();
  return <button type="button" onClick={async () => {
    if (!editor) return;
    const result = await editor.uploadPending();
    if (result.failed.length) throw new Error("Retry failed uploads before saving");
    await fetch("/api/documents/current", {
      method: "PUT",
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify(editor.getDoc()),
    });
  }}>Save document</button>;
}

<Editor uploadMode="deferred" onUpload={uploadAsset}
  createFileBlock={createAttachmentBlock} renderers={defaultRenderers}>
  <Editor.Plugin blocks={[attachmentBlock]}
    renderers={{ attachment: AttachmentView }} />
  <Editor.Content />
  <AddFiles />
  <SaveDocument />
</Editor>
```

## S3 또는 자체 저장소 연결하기

업로드 함수는 자체 API를 거치거나 짧게 유효한 S3 서명 업로드 URL을 받아 사용할 수 있습니다. 완료되면 계속 사용할 읽기 URL과 선택적인 파일 ID를 반환하세요. 비공개 인증 정보는 서버에 둡니다. 에디터는 콜백에 `{ blockId, kind: "image" | "file" }`를 전달하므로 종류별 검증·업로드 규칙을 적용할 수 있습니다. 같은 콜백에 `uploadMode="immediate"`를 지정하면 삽입 즉시 업로드합니다.

이미지 블록은 `props.src = "https://..."`로 외부 주소를 직접 사용할 수도 있습니다. 차트용 CSV/JSON 파일은 별도의 차트 데이터 리졸버로 연결합니다.

<Note>

S3 URL은 저장 위치입니다. 접근 권한, 서명 URL 만료, 파일 크기 제한, CORS는 앱과 저장 서버에서 설정해야 합니다.

</Note>
