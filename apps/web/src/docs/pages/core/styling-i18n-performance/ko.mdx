코어와 React 컨트롤에는 고정된 시각 테마나 아이콘 패키지가 없습니다. 쇼케이스 스타일은 이 사이트가 직접 작성한 CSS입니다. 컴포넌트에 Tailwind 클래스를 전달하거나 안정적인 `data-jul-editor-*` 훅에 앱 CSS를 쓰거나 두 방식을 함께 사용할 수 있습니다. 시각 플러그인은 바로 알아볼 수 있는 최소 스타일을 갖고 있으며 클래스 슬롯과 색상 속성으로 바꿀 수 있습니다.

## 앱 CSS로 테마 적용

래퍼 클래스와 앱 변수를 사용하세요. 차트 플러그인은 `--chart-1`부터 `--chart-6`까지 읽으므로 다른 UI와 색상을 맞출 수 있습니다. 밝은·어두운 테마 모두에서 대비와 초점 표시를 유지하세요.

```css
.my-editor .editor-content { color: var(--foreground); background: var(--background); }
.my-editor .editor-toolbar { border-color: var(--border); background: var(--card); }
.my-editor { --chart-1: #ee9b51; --chart-2: #7ca4ca; }
```

## Tailwind 클래스를 직접 전달하기

`Editor`, `Editor.Content`, 툴바의 각 기본 버튼은 문자열 `className`을 받습니다. 내부 영역이 여러 개인 컴포넌트는 객체도 받습니다. 툴바의 `container`·`button`·`text`는 각각 툴바 바깥쪽·기본 버튼·기본 레이블에 적용됩니다. 직접 전달한 자식 내용은 자식에 클래스를 지정하세요. 슬래시·태그·멘션 메뉴에도 같은 방식으로 적용하며, 필요 없는 메뉴는 렌더링하지 않으면 됩니다. 코어가 생성하는 블록은 `Editor.Content`의 Tailwind 임의 변형으로 안정적인 data 속성을 선택할 수 있습니다.

```tsx
import { Editor } from "@jul-editor/react";
import type { Doc } from "@jul-editor/core";

export function ArticleEditor({ doc }: { doc: Doc }) {
  return <Editor defaultValue={doc} className="rounded-xl border border-zinc-800 bg-zinc-950 text-zinc-100">
    <Editor.Toolbar className={{
      container: "flex gap-1 border-b border-zinc-800 p-2",
      button: "rounded-md px-2 py-1 hover:bg-orange-950 aria-pressed:bg-orange-900",
      text: "text-xs font-semibold",
    }}>
      <Editor.Bold />
      <Editor.Italic />
      <Editor.Heading level={2} />
    </Editor.Toolbar>
    <Editor.Content className="min-h-80 p-8 [&_[data-type=heading]]:font-bold [&_[data-type=quote]]:border-l-2 [&_[data-type=quote]]:border-orange-500" />
    <Editor.SlashMenu className={{
      container: "rounded-lg border border-zinc-700 bg-zinc-900 p-2 shadow-xl",
      item: "rounded-md px-3 py-2 hover:bg-zinc-800",
      text: "text-sm text-zinc-100",
      description: "text-xs text-zinc-400",
      empty: "p-3 text-sm text-zinc-500",
    }} />
  </Editor>;
}
```

아래 예제는 같은 슬롯 API에 이 사이트의 CSS 클래스를 전달한 실제 에디터입니다. Tailwind 앱에서는 위 코드처럼 클래스 문자열을 유틸리티로 바꾸면 됩니다.

## CSS 파일 없이 차트 색상 지정하기

플러그인 렌더러를 감싸고 `theme`을 데이터로 전달하세요. `series`는 최대 여섯 데이터 색상을, 나머지 값은 차트와 툴팁의 색을 정합니다. `className`은 각 차트 영역에 Tailwind 클래스를 적용합니다. 앱 테마가 없어도 차트의 기본 크기와 툴팁 배치는 작동합니다. 시각 플러그인이 가독성을 위해 인라인 기본 스타일을 사용하는 부분은 일반 Tailwind 클래스보다 우선하므로 색상은 `theme`으로 바꾸세요.

```tsx
import { ChartView, type ChartViewProps } from "@jul-editor/plugins/chart";
import { Editor } from "@jul-editor/react";

function BrandChart(props: ChartViewProps) {
  return <ChartView {...props}
    className={{ container: "rounded-xl border border-zinc-700 p-4", plot: "min-h-72", tooltip: "rounded-lg border border-zinc-700 bg-zinc-900 p-3 text-zinc-100 shadow-xl", legend: "flex justify-center gap-4 text-xs text-zinc-400", controls: "border-t border-zinc-700" }}
    theme={{
      series: ["#f97316", "#38bdf8", "#84cc16"],
      surface: "#101114", grid: "#38383f", muted: "#a1a1aa",
      tooltipBackground: "#18181b", tooltipForeground: "#fafafa", tooltipBorder: "#3f3f46",
    }} />;
}

<Editor.Plugin renderers={{ chart: BrandChart }} />
```

코드 워크스페이스는 `CodeWorkspaceIDEView`에 `theme={{ sidebar: "#17191f", accent: "#f97316" }}`와 `className` 슬롯을 전달하세요. 전체 연결법은 [플러그인 문서](/docs/plugins/code-workspace)에 있습니다. 다이어그램과 데이터 표도 각자의 슬롯 객체를 받습니다. 렌더러를 블록 키로 한 번 감싸면 앱 전체에 같은 설정을 적용할 수 있습니다. 다른 화면에서 시각 플러그인을 가져와도 기본 에디터에 스타일이 추가되지는 않습니다.

바로 써 볼 예제가 필요하면 [쇼케이스](/showcase)를 여세요. 디자인 토큰을 그대로 쓰는 **shadcn** 케이스를 보거나, **Custom**에서 프리셋(Notebook, Editorial, Midnight, Terminal, Studio, Blueprint, Canvas)을 고른 뒤 팔레트·글꼴·간격·모서리·페이지 배경·차트 색상을 조정할 수 있습니다. 테마 CSS를 `theme.css`에, React 컴포넌트를 앱에 복사하세요. 복사한 CSS에는 에디터 규칙과 현재 설정한 토큰 값이 들어갑니다. 설정을 바꿔도 코어에 테마 의존성은 추가되지 않습니다.

## 레이블과 문서 언어

기본 레이블에는 `locale="ko"` 또는 `locale="en"`을 지정하고, 제품 고유 문구는 `labels`로 덮어쓰세요. 번역된 UI와 저장되는 문서 내용은 분리합니다. 실행 중 레이블을 바꿔도 마운트된 에디터의 문서와 실행 취소 기록은 유지됩니다.

## 최적화 전에 측정하기

선택형 시각 플러그인은 사용할 때만 불러옵니다. 저장소의 타입 검사·벤치마크·브라우저 테스트를 실행한 뒤 실제 긴 문서와 커스텀 블록으로 성능 목표를 정하세요.

```sh
pnpm typecheck
pnpm bench
pnpm perf
pnpm e2e
```
