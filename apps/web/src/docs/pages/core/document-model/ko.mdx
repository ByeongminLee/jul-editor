`Doc`은 버전이 있는 블록 트리입니다. 블록 스펙에 따라 인라인 내용, 자식 블록 또는 둘 다 담을 수 있습니다. 예를 들어 목록 항목에는 텍스트와 중첩 목록 자식이 함께 들어갑니다. 편집 중 블록 ID를 유지해야 선택 영역, 실행 취소, 문서 비교가 같은 블록을 추적합니다.

## 제어형 상태와 저장

`defaultValue`는 에디터를 한 번 초기화합니다. `value`와 `onChange`를 함께 쓰면 제어형 에디터가 됩니다. `useAutosave`는 로컬 초안을 저장하고 앱의 서버 저장 함수를 호출할 수 있습니다. 서버 응답을 확인하고 실패 시 오류를 던져야 상태와 재시도가 정확합니다.

```tsx
import { useState } from "react";
import type { Doc } from "@jul-editor/core";
import { Editor, useAutosave } from "@jul-editor/react";

function SaveStatus() {
  const { status } = useAutosave({ key: "article:42", localDebounceMs: 500 });
  return <output aria-live="polite">{status}</output>;
}

function Article({ initialDoc }: { initialDoc: Doc }) {
  const [doc, setDoc] = useState(initialDoc);
  return <Editor value={doc} onChange={setDoc} locale="en">
    <SaveStatus />
    <Editor.Content />
  </Editor>;
}
```

## 초안 안전하게 복원하기

로컬 초안을 적용하기 전에 서버의 수정 시각과 비교하세요. 커스텀 블록을 복원할 때는 에디터에 등록한 것과 같은 블록 레지스트리를 전달합니다. 에디터가 마운트된 상태에서 `locale`이나 레이블만 바꾸면 문서와 실행 취소 기록은 유지됩니다.

관련 문서: 교환 형식은 [Markdown과 HTML](/docs/core/formats), 저장한 `Doc` 표시는 [읽기 전용 보기](/docs/core/read-only-view)를 보세요.
