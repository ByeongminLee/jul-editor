JulEditor는 "한 줄, 두 줄" 할 때의 줄에서 이름을 땄습니다. 문서는 한 줄씩 쌓입니다. JulEditor 문서는 블록으로 이루어진 트리입니다. 코어가 구조를 관리하고, React가 편집 화면을 제공하며, 선택형 플러그인이 차트 같은 블록을 더합니다. 문단 하나로 시작해 제품에 필요한 도구만 붙이면 됩니다.

## 첫 문서 만들기

문서에는 스키마 버전과 `blocks` 배열이 있습니다. 텍스트 블록은 고정된 ID, 타입, 속성, 인라인 내용을 가집니다. ID를 유지해야 편집 기록, 선택 영역, 문서 비교가 수정 전후의 같은 블록을 찾을 수 있습니다.

```ts
import type { Doc } from "@jul-editor/core";

const doc: Doc = {
  version: 1,
  blocks: [{
    id: "hello",
    type: "paragraph",
    props: {},
    content: [{ type: "text", text: "Hello, JulEditor." }],
  }],
};
```
